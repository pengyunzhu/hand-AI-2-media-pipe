# hand-AI-2-media-pipe

這是一個純網頁前端的 MediaPipe 手部辨識範例。使用者可以在手機瀏覽器或桌機瀏覽器啟用相機，並透過不同手勢觸發對應功能。

功能:
- 👍 拇指比讚：音樂播放
- ✊ 握拳：音樂暫停
- 🖐️ 張開手掌：停止並回到開始位置
- ✌️ 二指勝利手勢：快轉 5 秒
- 👉 伸出食指：倒退 5 秒

使用方式:
1. 開啟 `index.html`
2. 將本機 `demo.mp3` 放在專案根目錄（與 `index.html` 同一資料夾）
3. 點擊「開啟相機」
4. 對鏡頭比手勢即可控制音樂

這個範例採用 MediaPipe Hands 的 JavaScript CDN 版本，無須後端伺服器即可運行。
